## Knobs that no longer exist on the rebased tree

`TEX_RELEASED_MIB` (use `NX2NAVI_TEX_RELEASED_MB`), `VMA_BLOCK_MIB` (use `NX2NAVI_VMA_BLOCK_MB`), `TEX_RT_DEDICATED_MIB`,
`TEX_RT_TRIM`/`_COOLDOWN`/`_AGE`/`_PER_MIN`, `TEX_RT_RECYCLE` (upstream `TEX_REUSE`, default on), `TEX_RELEASED_YIELD`,
`TEX_RELEASED_LRU`, `TEX_DEDUPE`, `TEX_LIVE_EVICT`/`_IDLE`/`_GUARD` (upstream `TEX_EVICT`), `TEX_LIVE_RT_IDLE`,
`TEX_STATE_GEN`, `TEX_CHECK_SKIP`, `TEX_STALE_GONE`, `TEX_STALE_LIVE`, `POOL_KH`, `GPU_WAIT` (upstream `WB_SPLIT`),
`FINISH_DEFER`, `EVENT_WAITS`, `AO_ORDER`, `DIFF_THREADS`, `SHADOW_NT`, `SHADOW_GAP_KIB`, `SHADOW_REWRITE`,
`TRACE=tex`. The justfile recipes still set several of them (`play`: `TEX_RELEASED_MIB`, `GPU_WAIT`; `try`:
`TEX_RELEASED_YIELD`, `AO_ORDER`, `SHADOW_NT`; `try-vram`: the RT and LIVE knobs, `STALE_LIVE`): harmless on the new
exe (unknown keys), to be cleaned up when `build` moves.

## Changed behaviour to know

- F9 is upstream's debug menu when `debug_menu = 1`; our mark fires on F9 only while it is off (L3+R3 and mark.req always).
- F5/F6/F12 debug keys (0062) are also bindable game keys upstream (input_map.h KEY_F5...): they still fire both.
- `NX2NAVI_TRACE` bits: `counters` 1024, `nvn` 2048 (upstream `coop` is 512).
- Translator identity changes (old `e7a46252...`, tld `7131bd39...`, new `53afad07...`): new shader cache keys.

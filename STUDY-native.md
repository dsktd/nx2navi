# Desktop-native replacements: where the frame could go (tracker #187, 2026-11-12)

Desk study, CPU only, no new runs. Build: play49 (`dmabuf` f12f898 = play48 + upstream PR #730), Hyrule Field f2663
standing, presents 1800-3000, 6900 XT / RADV. Sources: `.lab/fc-prof/p49.prof` (replay-thread sampler, read with
`tools/prof-window --tree`, 1190 presents), `.lab/fc-bstat-1/run.log` (p49stat a1f225f, `BIND_STATS=1 TRACE=perf`),
`.lab/fc-d49-1/run.log` (`tools/perf_summary.py`), dumps `build/v111/dump/f77135`, `f77131`, `f39376` (passes.txt).
Standing-still windows only; every "expected" figure is derived from the profile, not an A/B.

## Ranking

The frame now: interval 20.0 ms (50-53 fps) = replay 14.5-15.7 ms work + ~4.5 ms the replay waits for the game.
GPU busy 12.0-12.4 ms, 5.6 ms a frame starved: the GPU is not the bound until the interval drops below ~12.5 ms.

## Facts behind the table

- **Replay thread per frame** (p49.prof, ms per present): `vk_exec_record` 14.0, `walk` 13.0, `op_draw_impl` 9.9
  (`prepare_draw_ex` 8.4: `bind_resources` 4.5, `shader_for` 0.87, `bind_vertex_buffers` 0.63, `feedback_prepare` 0.55,
  `graphics` 0.51; the other 1.5 is draw emission), `maybe_split` 0.75, `report_counter` 0.70,
  `vk_mem_mirror_begin` 0.65, `vk_texture_new_submit` 0.40, `plat_cond_wait` 4.0. Libc self time 1.2 ms shows as
  `_dl_mcount_wrapper` and 0.36 as `__default_morecore`: misnamed libc internals (copies, allocation), not profiling.
  `libvulkan_radeon` 0.7 ms on this thread.
- **Draws**: 3,250 draws a frame (BIND_STATS cumulative, frames 1800-3000 of fc-bstat-1: 2.04M -> 5.94M), so the
  replay pays ~3 us a draw and 4.5 us of total work a draw. Dumps of the field elsewhere count 650-750 draws in
  `passes.txt` (f77135/f77131) and 1,753 in f39376: the dump's "draws N" and BIND_STATS do not count the same thing
  (open).
- **Pass mix** (f77135, 225 passes): 126 compute dispatches; render passes: shadow (1600x1600, 2400x2400) 163 draws
  in 5 passes, full-res 1080p 162 in 26, half/quarter res 122 in 23, tiny (<= 256x256: LUTs, probes, mip and bloom
  chains) 161 in 41, interface at 2560x1440 132 in 3.
- **GPU timeline** (fc-bstat-1 frame 3000): busy 12.04 ms, starved 5.61, queued idle 3.11 (before replay parts 1.66,
  mirror prologues 1.39); 16.6 replay parts a frame; mirror copies 0.63 ms GPU.
- **Upstream checked** (origin/main a32597b, nothing newer on 2026-11-12; open PRs): no descriptor buffer,
  device-address uniform buffers or pass memoization. Related: replay workers (432b4e4 on, 94dd340 off again; our
  `REPLAY_WORKERS=3` on play49: no gain), `MIRROR_HOT` 4ba78a7, PR #731 (area-load staging inside boot-made blocks),
  PR #730 (dma-buf, in play49), PR #770 (DLSS FG), PR #742/#593 (FSR 4 on Linux), PR #636 (shared translation work).
- Not run: `tools/crit_path.py` (no CRIT recording of play49 exists), `tools/shader_census.py` (no extracted RomFS
  under `NX2navi/build/extracted`).
